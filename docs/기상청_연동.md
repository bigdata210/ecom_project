# 현재 위치 기상청 관측 연동

Vercel 환경변수 `data_api`에 공공데이터포털 인증키를 등록한다.
기상청 **단기예보 조회서비스** 활용신청 승인이 필요하다.
https://www.data.go.kr/data/15084084/openapi.do

Production 환경에 적용한 후 새로 배포한다. 키는 Python 서버에서만 읽으며
브라우저나 GitHub에 넣지 않는다. Encoding/Decoding 키 모두 처리한다.

대시보드 또는 기상정보에서 '현재 위치로 날씨 조회'를 누르고 브라우저의
위치 권한을 허용한다. HTTPS가 필요하다. 한국 영역 안의 좌표를 기상청
격자로 변환하여 초단기실황 기온·습도·풍속·1시간 강수량을 표시한다.
관측시각은 KST로 표시한다. 하늘 상태·기압·예보·과거조회는 제공하지 않는다.
자료가 없는 항목은 '자료 없음'으로 표시하며 예시값으로 대체하지 않는다.

서버는 최신 정시 자료의 배포 지연을 고려해 40분을 빼고 요청하고,
자료없음(03)이면 이전 시간으로 최대 두 번 더 조회한다.
격자별 10분 단위 메모리 캐시를 사용한다. 서버리스 인스턴스 간 캐시는
공유되지 않는다. 좌표를 DB에 저장하지 않지만 요청 URL에 포함되므로
호스팅 접근 로그에는 기록될 수 있다.

현재 위치는 사용자의 기기 위치이며 시료 채취지점의 날씨를 뜻하지 않는다.
연동 테스트는 모의 API 응답으로 수행하며 실제 키의 승인·유효성은
Vercel 배포 후 조회 성공으로 확인해야 한다.
