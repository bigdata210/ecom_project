# 비공개 Excel 양식

실제 측정값이나 고객 정보가 포함될 수 있는 Excel 양식은 Git에 저장하지 않습니다. 로컬 변환 기능을 실행하거나 EXE를 빌드하려면 승인된 양식을 이 폴더에 별도로 배치해야 합니다.

- `organic_template.xlsx`: 유기인·VOC 출력 양식
- `metal_stage1.xlsx`: 중금속 1차 출력 양식
- `metal_stage2.xlsx`: 중금속 2차 출력 양식

현재 `.gitignore`는 XLS/XLSX 파일을 제외합니다. 웹 서비스에서는 원본 양식과 매핑 버전을 업체별 비공개 파일 저장소에서 관리할 계획입니다.

기존 샘플 기반 통합 테스트는 개인 PC의 샘플 경로를 참조합니다. 웹 전환 시 비식별 테스트 자료와 실행 경로를 별도로 정리해야 합니다. 저장소만 복제한 상태에서는 원본 샘플이 필요한 테스트를 실행할 수 없습니다.
