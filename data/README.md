# 수질 대시보드 기준자료

## 측정망과 항목

대시보드는 사용자 요청에 따라 **자동측정망**만 조회한다.
사용자 제공 `물환경 수질자동측정망(실시간) 운영결과 DB_물 환경_코드_코드명.xlsx`
의 siteid 시트(5~29행, A:B / D:E / G:H / J:K)에서 측정소 71개를 읽었다.
항목코드 시트에서 통신상태 M01을 제외한 44개 항목을 읽었다.
단위와 API 필드는 제공 HWP의 2.1.5 응답 명세에서 가져왔다.
M81은 가이드에 단위가 없어 '원문 단위 미기재'로 표시한다.
센서1/2/3과 ECD 항목은 합치지 않는다. 금속·VOC는 µg/L, 다른 항목은
각 원문 단위를 사용한다. -999는 코드표에 따라 정량한계 미만으로 제외한다.

일반 수질측정망·방사성·먹는물 코드표는 확인했으나 이 평균에 혼합하지 않았다.
개인 측정 PDF 변환용 56개 항목과 공공 자동측정망 제공항목은 서로 다르다.

## 소재지 연결

사용자 제공 자동측정소 코드표에는 주소·좌표가 없다. 아래 환경부 문서의
자동측정망 표에서 이름이 일치하는 측정소를 찾아 소재지를 연결했다.

- 물환경측정망 설치·운영계획, MyWater 공개 게시본(2024/03)
- https://www.water.or.kr/upload/board/2024/03/20240320180535_1.pdf
- PDF 213~219쪽 (문서 인쇄쪽 207~213)
- 71개 중 69개 소재지 연결. 미호천(S03006), 임하호(S02016)는 미연결.
- 행정구역 이름 강원도→강원특별자치도, 전라북도→전북특별자치도 정규화.
- 소재지 미연결 측정소는 전국/수계/개별 측정소 조회에는 포함하지만
  시도·시군구 평균에는 포함하지 않는다. 신규·이전·폐쇄 여부는 코드표 범위의 한계가 있다.

## 지도

통계청 SGIS 2018 행정구역 경계, 공공누리 제1유형.
원자료 배포: https://github.com/southkorea/southkorea-maps/tree/master/kostat/2018/json
`skorea-provinces-2018-topo.json`을 SVG 경로로 투영·단순화한
`web/korea-regions.json`을 사용한다. 원자료 수집일 2018-12-24.
법적 경계 또는 측정소 좌표를 나타내는 지도가 아니다.

## API와 계산

- 공식 서비스: https://www.data.go.kr/data/15081073/openapi.do
- 서버 환경변수: `water_api_key` (브라우저 전송·Git 저장 금지)
- getRealTimeWaterQualityList, resultType=xml
- siteId, startDate, endDate로 일자(KST) 조회. 최대 10개 측정소씩 묶고
  numOfRows=1000, pageNo를 증가시켜 totalCount 전체 조회.
- 일부 페이지 누락·건수 변경·시간 초과 시 평균을 반환하지 않는다.
- 기본 날짜: KST 오늘의 100일 전. 가이드상 약 3개월 공개 지연을 고려한
  조회 기본값일 뿐 최신 공개일이라고 보장하지 않는다.
- 일간 평균: 선택일·측정소·항목의 유효 관측 숫자를 모두 합산 / 유효 건수.
  관측 건수 가중 산술평균이며 측정소별 평균의 단순평균은 아니다.
- 선택일 최종값 평균: 각 측정소에서 그 날짜의 최종 기록 한 개를 선택한 뒤
  유효 숫자만 평균. 최종 기록이 결측이면 이전 기록으로 채우지 않는다.
- 빈값, ND, 불검출, 부등호가 붙은 값, -999, NaN/Inf는 제외하고 실제 0은 포함.
- 동일 측정소·시각·선택 항목의 값이 같으면 중복제거, 충돌하면 오류.
- 원본이 날짜만 제공하면 시간단위 실시간이라고 표시하지 않는다.
- 10분 단위 인스턴스 내 메모리 캐시. DB 저장이나 정기 수집은 하지 않는다.

## 배포와 검증

Vercel Production 환경에 water_api_key를 저장하고 최신 커밋으로 배포한다.
키에는 국립환경과학원 수질 DB 활용승인이 필요하다.
기상청의 data_api_key와 별개다. 환경변수 실제 값은 로컬에 가져오지 않는다.

`python -m unittest test_water test_weather -v`로 모의 응답·평균·페이지네이션·
중복·결측·키 비노출을 검증한다. 실제 API 응답은 배포 후 별도로 확인한다.
전달 가이드상 API 명칭과 달리 약 3개월 전 자료를 월 1회 공개하므로,
현재 실시간 감시가 필요하면 별도 실시간 제공 API와 활용권한 확인이 필요하다.
